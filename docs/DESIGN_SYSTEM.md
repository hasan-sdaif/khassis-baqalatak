# نظام التصميم (DESIGN_SYSTEM.md)

> لغة «الزجاج السائل» على طراز iOS — عربية RTL أولاً، بلا إيموجي، أيقونات SVG أحادية.

## الرموز (Tokens)

### الألوان (فاتح / داكن)
| الرمز | فاتح | داكن | الاستخدام |
|---|---|---|---|
| primary | `#1e6b4f` أخضر عميق دافئ | `#4ea37a` | الإجراءات الأساسية، الروابط |
| accent | `#d97706` عنبري | `#f0a63c` | الأظرف، التنبيهات الودية |
| background | `#f6f4ee` محايد دافئ | `#171c17` | الخلفية |
| destructive | `#b3261e` | `#e5544b` | العجز/الأخطاء |
| المخططات | أخضر/عنبري/زيتوني/بني داكن | نفس العائلة | ألوان مفهومة لعمى الألوان + وسوم نصية |

**لا نيلي ولا أزرق** في أي عنصر (قيد المواصفة 10.6).

### الخط
IBM Plex Sans Arabic (300–700) عبر next/font (subset تلقائي، swap). `font-feature-settings: "tnum"` لكل الأرقام المالية (محاذاة الأعمدة).

### المواد الزجاجية الخمس (globals.css)
| المادة | الاستخدام | التضبيب |
|---|---|---|
| `glass-ultrathin` | خلفيات خفيفة داخل البطاقات | 8px |
| `glass-thin` | أزرار ثانوية، شرائح | 10px |
| `glass` (regular) | البطاقات | 18px + saturate 160% |
| `glass-thick`/`glass-chrome` | الأشرطة: الترويسة، شريط التبويب السفلي، الشريط الجانبي | 28px + saturate 180% + إضاءة داخلية |
| `glass-row` | صفوف القوائم الطويلة (بديل مصمت شبه شفاف بلا تضبيب — أداء) | — |

كل مواد الزجاج: حافة 1px شفافة + إضاءة علوية inset + ظل ناعم. **البدائل الإلزامية**: `@supports not (backdrop-filter)` ← مصمت؛ `prefers-reduced-transparency` ← مصمت؛ `prefers-contrast: more` ← حدود أوضح؛ وإعداد المستخدم «تقليل الشفافية» (`reduce-transparency` class) يتجاوز الكشف.

### الخلفية الشفقية
3 بقع mesh (أخضر/عنبري/زيتوني) بحركة 38–52s + طبقة ضجيج SVG دقيقة تمنع التقطيع. تتوقف مع `prefers-reduced-motion`.

## الأصداف الثلاثة (Layout Shells)

| الصدفة | العرض | البنية |
|---|---|---|
| الهاتف (الأساس) | < 700px | عمود واحد + **شريط تبويب زجاجي سفلي** (5 وجهات) + شريط عنوان زجاجي أعلى + بطاقات بعرض كامل (هوامش 16px) + `env(safe-area-inset)` + `dvh` |
| التابلت | 700–1180px | شريط جانبي زجاجي مضغوط (أيقونات 68px) + منطقة محتوى أوسع + شبكتان |
| الحاسوب | ≥ 1180px | شريط جانبي كامل (240px، أسماء) + محتوى حتى 1280px + 3 أعمدة عند الحاجة |

التنقل: `AppShell` (src/components/glass/app-shell.tsx) — يطبق dir/lang/theme/classes على `<html>` ويدير الحالة النشطة.

## الأيقونات

- **lucide-react** فقط (ترخيص ISC، أحادية `currentColor`، `strokeWidth=1.75`، `aria-hidden`).
- سجل التصنيفات: `src/components/icons/category-icons.tsx` يربط كل تصنيف/مجموعة بأيقونة (43 مدخلاً) + أيقونة احتياطية للجديد.
- **الاتجاهية تُقلب فقط للأسهم/الشيفرون** عبر `.flip-x` في RTL.
- **صفر إيموجي** في الواجهة والتقارير والنصوص (قاعدة CI).

## الحركة

دخول `pop-in` 320ms بمنحنى نابض؛ أرقام متغيرة بومضة `flash-num`؛ شرائح سفلية ووسطاء shadcn/radix حيث يلزم. كل شيء يتوقف مع `prefers-reduced-motion`.

## الطباعة (ليست زجاجاً!)

`@media print`: إخفاء الخلفية/الأشرطة/`.no-print`، **الزجاج يصبح أبيض مصمتاً بحدود #bbb بلا ظلال**، `.print-page` لفصل الصفحات، `.print-avoid-break` لمنع كسر الصفوف، `thead` يتكرر، `@page { margin: 14mm }`. وثيقة التقرير نفسها (`#report-doc` في reports-view) مصممة ورقياً: A4/A5/Letter/80mm + وضع توفير الحبر (رمادي).

## المكونات (src/components/glass/glass.tsx)

`GlassCard` `GlassRow` `GlassButton` (primary/ghost/danger × sm/md/lg، ≥44px) `Pill` (5 نغمات) `StatTile` `SectionTitle` `EmptyState` `Spinner` `SkeletonRows` — كلها RTL-native بخصائص منطقية (ms/me/inline).

## قواعد الاستخدام

1. الزجاج لهيكل الواجهة والبطاقات المهمة فقط — **ليس لكل صف** (استخدم `glass-row`).
2. أي نص فوق زجاج يحقق AA (خطوط داكنة على زجاج فاتح والعكس).
3. كل عنصر تفاعلي ≥ 44px مع حالات hover/active/focus مرئية.
4. الأرقام دائماً `tabular-nums` والمبالغ عبر `formatBHD` (3 منازل + د.ب).
5. الأسماء اللاتينية داخل نص عربي: `dir="auto"` (البيانات مختلطة).
