## ملاحظات إعادة الإنتاج

1. `test:api` يتطلب خادماً حياً (`bun run dev`) ويتخطى بشفافية مع رسالة واضحة عند غيابه — لا يُعد التخطي نجاحاً.
2. حدود المعدل داخل الذاكرة: عند إعادة تشغيل `test:api` مباشرة بعد تشغيل سابق قد تظهر 429 مبكرة في اختبار الإغراق — انتظر دقيقة أو أعد تشغيل الخادم.
3. `DATABASE_URL`: انتبه لمتغير بيئة مصدَّر في جلسة الطرفية يسبق ملف `.env` (سلوك Prisma المعروف) — استخدم `env -u DATABASE_URL` عند الحاجة لعزل القيمة.
4. تصنيف الكتالوج المخزن يحمل تاريخ جولات سابقة؛ قواعد التصنيف الجديدة تسري عند إعادة الاستيراد/التحرير، بينما الحارس الدلالي يحمي الخطة والأظرف فوراً بغض النظر عن التصنيف المخزن.
